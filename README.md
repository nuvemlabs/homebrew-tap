# nuvemlabs Homebrew tap

```bash
brew install nuvemlabs/tap/secrets
brew install nuvemlabs/tap/secrets-bridge   # also installs secrets
```

| Formula | Description |
|---------|-------------|
| [`secrets`](https://github.com/nuvemlabs/secrets) | OS-native secret storage for bash and zsh (Keychain, libsecret) |
| [`secrets-bridge`](https://github.com/nuvemlabs/secrets-bridge) | Fetch cloud and wallet secrets into local .env, Postman and Bruno files (depends on `secrets`) |

The formula source of truth lives in each project's `packaging/homebrew/` directory; this tap carries the published copy.
